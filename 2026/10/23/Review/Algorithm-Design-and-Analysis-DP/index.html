第3章 动态规划

动态规划四步曲（各题严格按此展开）：

  1. 刻画最优解结构（证明最优子结构）；
  2. 递归地定义最优值（状态转移方程）；
  3. 自底向上计算最优值（填表）；
  4. 根据计算结果构造最优解（回溯标记）。

核心口诀：“自顶向下分析，自底向上求解”——先站在最后一个元素的角度枚举决策，再从小到大填表。

SORTBOT 框架（每道 DP 题的通用总结模板）

动态规划的基本要素（一道题能不能用 DP 的判据）：

  1. 最优子结构性质：问题的最优解包含其子问题的最优解。验证套路是反证（剪贴法）——假设由最优解导出的子问题解不是最优的，就能"贴"出一个更好的解，与最优性矛盾；
  2. 子问题重叠性质：递归求解时同一个子问题会被反复计算（画递归树看重复结点）。DP 用一张表把已解决的子问题答案保存下来，每个子问题只算一次；自底向上填表是"全算"，备忘录方法（自顶向下、按需递归 + 查表）是"用到才算"，二者复杂度同阶。

入门：青蛙跳台阶（一题多解）

问题描述

一只青蛙一次可以跳上 1 级台阶，也可以跳上 2 级台阶。求该青蛙跳上一个 n 级的台阶总共有多少种跳法？

这是本章的入门题：同一个问题可以用朴素递归、分治（中点分解）、动态规划三种姿势解决，通过对比体会"什么时候必须用动态规划"。

解法一：朴素递归（直接翻译递归方程）

考察最后一步：跳 1 级（剩余 n−1 级）或跳 2 级（剩余 n−2 级），两类不重不漏：

$$f(n) = f(n-1) + f(n-2), \qquad f(0) = f(1) = 1$$

直接写成递归函数即可，但递归树中 f(n−2)、f(n−3)、……被反复计算（子问题重叠），复杂度是黄金比例指数级 O(1.618ⁿ)。这正是"分而不独立"的场景——分治法要求子问题互不重叠，此处失效，需要下两种解法。

解法二：分治——中点分解（倍增恒等式）

换一种分法：不按"最后一步"分，而是设一个中间点 m，把 0→n 的路径按"是否经过台阶 m"分成不重不漏的两类：

  • 经过 m：路径 = 先从 0 走到 m，再从 m 走到 n。由平移不变性，两段各有 f(m)、f(n−m) 种，共 f(m) · f(n−m) 种；
  • 不经过 m：每步只能跳 1 或 2 级，想跳过 m 只能从 m−1 直接跳到 m+1——即路径必经过 m−1，并从那里一步跳过 m。这样的路径有 f(m−1) · f(n−m−1) 种。

两者相加得到倍增恒等式：

$$
f(n) = f(m) \cdot f(n-m) + f(m-1) \cdot f(n-m-1), \qquad m = \lfloor n/2 \rfloor
$$

  • n 为偶数时即 f(n) = f(n/2)² + f(n/2−1)²（递归树上"分治思想"一页给出的式子就是它）；课件问"n/2 一定是整数吗？"——不必是：取 m = ⌊n/2⌋，一般恒等式对奇偶都成立；
  • 验算：f = (1, 1, 2, 3, 5, 8, 13, 21, 34)，f(8) = f(4)² + f(3)² = 25 + 9 = 34 ✓；奇数 f(7) = f(3)f(4) + f(2)f(3) = 15 + 6 = 21 ✓；
  • 递归实现时让函数一次返回 (f(k−1), f(k)) 两个值，每层只递归一次：T(n) = T(n/2) + O(1) = O(log n)：

这就是 Fibonacci 快速倍增法，与矩阵快速幂（[[1,1],[1,0]] 的 n 次幂）同源——纯分治、不用动态规划，也能把复杂度做到 O(log n)。

解法三：动态规划填表

把重叠子问题"存表重用"：从 f(0)、f(1) 出发自底向上递推，每个 f(k) 只算一次——O(n) 时间，空间可滚动到 O(1)。

热身：木条游戏

问题描述

你有一根长度为 n（n 为整数）的木条，每次可以执行以下任意操作：

  1. 选择一根木条并在某处切割，得到两块长度均为整数的新木条；
  2. 停止切割并计算总分——总分 = 各木条长度对应的价格之和。

长度—价格表（只标到长度 10，故每段长度不能超过 10）：

长度12345678910
价格1589101517202326

目标：求长度为 n 的木条能切出的最高总分。

状态转移方程

(a) 推导过程——考察"第一段切多长"

设 dp(k) 表示长度为 k 的木条的最高价值。站在切第一刀的角度枚举第一段的长度 i：切下长 i 的一段卖掉（得 p[i]），剩下长度 k−i 的木条是与原问题同构的子问题：

  • 第一段长 1：dp(k) = p[1] + dp(k−1)；
  • 第一段长 2：dp(k) = p[2] + dp(k−2)；
  • ……
  • 第一段长 k（整根不切，前提是 k ≤ 10 有标价）：dp(k) = p[k] + dp(0)。

到底第一段切多长？——取使 dp(k) 最大的 i。这就是"找切割点"的决策。

(b) 状态转移方程

$$
dp(k) = \max_{1 \le i \le \min(k, 10)} \big\lbrace\ p[i] + dp(k-i)\ \big\rbrace, \qquad dp(0) = 0
$$

同时记录取得最大值的切割点（第一段长度），供构造方案。时间复杂度 O(n·min(n,10)) = O(n²)，空间 O(n)。

  • Subproblem: dp(k) —— 长度 k 的木条最高价值；
  • Original Problem: dp(n)；
  • Relation: 找切割点，$dp(k) = \max_i \lbrace p[i] + dp(k-i) \rbrace$；
  • Topology: dp(1), dp(2), …, dp(n)；
  • Base case: dp(0) = 0（初始价格表）；
  • Original Solution: 记录每个 dp(k) 对应的切割点，从 n 逐段回溯；
  • Time Complexity: O(n²)。

解法二：备忘录递归

按方程直接写自顶向下的递归 V(k)，用 memo[] 记录已算过的子问题；与图像压缩一节的做法完全同构。本题递归树会大量重复"长度 k−i"的子链，是子问题重叠性质最直观的例子：朴素递归是指数级，加一张备忘录表后每个 dp(k) 只算一次，复杂度回到 O(n²)。

3.1 矩阵连乘积

引例：加括号的顺序影响巨大

两个矩阵相乘：A 是 p×q，B 是 q×r，则 C = AB 需要 p·q·r 次数乘。三个矩阵连乘时，加括号顺序不同代价可能差一个量级。设 A₁ 为 10×100、A₂ 为 100×5、A₃ 为 5×50：

  • (A₁A₂)A₃：先算 10×100×5 = 5000 次，再算 10×5×50 = 2500 次，共 7500 次；
  • A₁(A₂A₃)：先算 100×5×50 = 25000 次，再算 10×100×50 = 50000 次，共 75000 次。

四个矩阵有 5 种完全加括号方式（一般地，n 个矩阵的加括号方式数是 Catalan 数，指数级）。矩阵连乘问题：给定 n 个矩阵的连乘积 A₁A₂⋯Aₙ，求数乘次数最少的完全加括号方式。

问题描述与记号

矩阵维数用 p 数组表示：Aᵢ 是 p_{i−1} × pᵢ，n 个矩阵对应 p₀, p₁, …, pₙ 共 n+1 个数。例：A[1:4] 各矩阵为 30×35、35×15、15×5、5×10，则 p = (30, 35, 15, 5, 10)。

记 A[i:j] = AᵢA_{i+1}⋯Aⱼ，m[i][j] = A[i:j] 所需的最少乘次数，原问题即求 m[1][n]。

最优子结构

设 ((A₁⋯A_k)(A_{k+1}⋯A_n)) 是 A[1:n] 的一个最优计算次序（最优解在 A_k 与 A_{k+1} 之间断开，即最后一次相乘是 (A[1:k])·(A[k+1:n])），则子矩阵链 A[1:k] 与 A[k+1:n] 的计算次序也必然是最优的。

反证：若 A[1:k] 存在计算量更少的次序 A′[1:k]，用它替换原次序中的子链，可构造出总计算量更少的 A[1:n] 计算次序，与"最优"矛盾。∎

状态转移方程

(a) 推导过程——考察"最后一次相乘"的断开位置

对子问题 A[i:j]（i < j），它的完全加括号方案一定在某处把链断成两截：A[i:j] = (A[i:k])(A[k+1:j])，最后一次相乘把两个子结果矩阵乘起来。断开位置 k 有 j − i 种选择（i ≤ k < j）。固定 k 时总计算量为三部分之和：

$$
m[i][k] + m[k+1][j] + p_{i-1} p_k p_j
$$

三项依次是：左链 A[i:k] 的最优计算量、右链 A[k+1:j] 的最优计算量、把两个子结果矩阵合并的代价。

(b) 状态转移方程

$$
m[i][j] = \begin{cases}
0, & i = j \quad \text{（单一矩阵无需相乘）} \\
\min\limits_{i \le k < j} \big\lbrace\ m[i][k] + m[k+1][j] + p_{i-1} p_k p_j\ \big\rbrace, & i < j
\end{cases}
$$

最优值为 m[1][n]；同时记录最优断开位置 s[i][j] = k 用于构造最优解。每个 m[i][j] 枚举 O(n) 个 k，共 O(n²) 个子问题，时间复杂度 O(n³)，空间 O(n²)。

3.3 最长公共子序列

基本概念

子序列：给定序列 X = ⟨A, B, C, B, D, A, B⟩ 和 Z = ⟨B, C, D, B⟩，若 Z 的各元素是 X 中按下标递增依次出现的（这里是下标 ⟨2, 3, 5, 7⟩），称 Z 是 X 的子序列——不要求连续。

公共子序列：若 Z 既是 X 的子序列又是 Y 的子序列。例：X = ⟨A,B,C,B,D,A,B⟩，Y = ⟨B,D,C,A,B,A⟩，则 Z₁ = ⟨B,C,A⟩ 是公共子序列，而 Z₂ = ⟨B,C,B,A⟩ 是它们的最长公共子序列（LCS），长度为 4。

问题：给定序列 X = ⟨x₁, ⋯, xₘ⟩ 和 Y = ⟨y₁, ⋯, yₙ⟩，求 X 和 Y 的最长公共子序列。穷举法要列出 X 的所有 2ᵐ 个子序列再逐一检查，指数时间不可行。

最优子结构

设 Z = ⟨z₁, ⋯, z_k⟩ 是 X 与 Y 的 LCS，则（三种情形）：

  1. 若 x_m = y_n = z_k：则 Z_{k−1} = ⟨z₁, ⋯, z_{k−1}⟩ 是 X_{m−1} 与 Y_{n−1} 的 LCS。（反证：若不是，X_{m−1} 与 Y_{n−1} 有更长的公共子序列 W，则 W 拼上 x_m 是 X 与 Y 更长的公共子序列，矛盾）
  2. 若 x_m ≠ y_n 且 z_k ≠ x_m：则 Z 是 X_{m−1} 与 Y 的 LCS。（反证：若 X_{m−1} 与 Y 有长度大于 k 的公共子序列 W，则 W 也是 X 与 Y 的公共子序列，与 Z 最长矛盾）
  3. 若 x_m ≠ y_n 且 z_k ≠ y_n：则 Z 是 X 与 Y_{n−1} 的 LCS。（同理）

最长公共子序列问题具有最优子结构性质。∎

状态转移方程

(a) 推导过程——考察前缀的最后一对字符

由最优子结构，把子问题定义为前缀：c[i][j] 表示 X 的前 i 个字符 Xᵢ 与 Y 的前 j 个字符 Yⱼ 的 LCS 长度。考察子问题的"最后一对字符"x_i 与 y_j：

  • x_i = y_j：这个公共字符一定可以放进 LCS 的末尾（情形 1），问题规模各退一格——c[i][j] = c[i−1][j−1] + 1；
  • x_i ≠ y_j：LCS 的最后一个字符不可能同时等于 x_i 和 y_j，故最优解要么"不用 x_i"（情形 2），要么"不用 y_n"（情形 3）——两种来源取大者：c[i][j] = max{ c[i−1][j], c[i][j−1] }。

同时记录每个格子取值的来源 b[i][j]（↖ 左上 / ↑ 上 / ← 左），供回溯构造 LCS。

(b) 状态转移方程

$$
c[i][j] = \begin{cases}
0, & i = 0 \text{ 或 } j = 0 \\
c[i-1][j-1] + 1, & i, j > 0;\ x_i = y_j \\
\max\lbrace c[i-1][j],\ c[i][j-1] \rbrace, & i, j > 0;\ x_i \ne y_j
\end{cases}
$$

最优值 c[m][n]。共 θ(mn) 个不同子问题，自底向上每个 O(1) 求解，时间复杂度 O(mn)，空间 O(mn)。

3.4 最大子段和

问题描述

给定由 n 个整数（可能为负）组成的序列 a₁, a₂, ⋯, a_n，求该序列的连续子段和的最大值：

$$
\max\big\lbrace\ 0,\ \max_{1 \le i \le j \le n} \sum_{k=i}^{j} a_k\ \big\rbrace
$$

当所有整数均为负时，规定最大子段和为 0（取空子段）。例：(a₁, ⋯, a₆) = (−2, 11, −4, 13, −5, −2)，最大子段和为 a₂ + a₃ + a₄ = 11 − 4 + 13 = 20。

状态转移方程

(a) 推导过程——考察"以 a[i] 结尾"

直接定义"前 i 项的最大子段和"没有好转移（最优子段终点未知、起点未知，两个方向都断不干净）。正确的子问题是给子段锚定一个端点：

设 dp(i) = 以 a[i] 为结尾的最大子段和。考察 a[i] 前面那段累积 dp(i−1)：

  • 若 dp(i−1) > 0：接上前段更有利——dp(i) = dp(i−1) + a[i]；
  • 若 dp(i−1) ≤ 0：前段是累赘，起点重置为 i——dp(i) = a[i]。

全局答案不固定结尾在哪：ans = max₁≤i≤n dp(i)（最优子段一定以某个 i 结尾）。

(b) 状态转移方程

$$
dp(i) = \max\big\lbrace\ dp(i-1) + a[i],\ a[i] \big\rbrace, \qquad dp(1) = a[1], \qquad ans = \max_{1 \le i \le n} dp(i)
$$

mark(i) 记录"是否起点重置"。时间复杂度 O(n)、空间 O(1)——本章最轻的一道题。

  • Original Problem: max dp(i)；
  • Relation: dp(i) = max{dp(i−1) + a[i], a[i]}（是否起点重置）；

  • Base case: dp(1) = a[1]；
  • Original Solution: mark(i) 记录重置点，重置处即最优子段起点，dp 最大处即终点；
  • Time Complexity: O(n)。

解法二：分治法

最大子段和还有经典的分治解法（也是 DP 之外的另一条正路）：把 a[left…right] 从 mid 分成两半，最优子段只有三种可能——

  1. 完全落在左半 a[left…mid]：递归求解；
  2. 完全落在右半 a[mid+1…right]：递归求解；
  3. 跨越中点：一定是"左半以 mid 结尾的最大后缀 + 右半以 mid+1 开头的最大前缀"，两个方向各线性扫一遍即可。

$$
T(n) = 2T(n/2) + O(n) \ \Rightarrow\ T(n) = O(n \log n)
$$

另一个 O(n) 视角是前缀和：子段和 Σ_{k=i}^{j} a_k = S_j − S_{i−1}，要让子段和最大就让被减的前缀最小——ans = max_j (S_j − min_{i<j} S_i)，一遍扫描维护前缀最小值即可，与 DP 异曲同工。

3.5 凸多边形最优三角剖分

基本概念

凸多边形：任意一条边向两方延长成直线，多边形其余各边均在此直线同旁。连接多边形内两个不相邻顶点的线段称为弦。

三角剖分：将凸多边形分割成互不重叠的三角形的弦的集合 T——n 个顶点的凸多边形的三角剖分含 n − 3 条弦和 n − 2 个三角形。

权函数 w：给每个三角形赋一个权（如三边权之和＝周长、面积、顶点权和等）。剖分的权 = 各三角形权之和。问题：求权值之和最小的三角剖分。

与矩阵连乘的对应关系

这是本章最漂亮的"一题两面"：

矩阵连乘凸多边形三角剖分
n 个矩阵的连乘积n + 1 个顶点的凸多边形
完全加括号方式三角剖分（弦的集合）
最后一次相乘的断点 k根三角形 v₀v_k v_n
子链 A[1:k]、A[k+1:n]子多边形 ⟨v₀⋯v_k⟩、⟨v_k⋯v_n⟩

完全加括号的矩阵连乘对应一棵完全二叉树（叶 = 矩阵，内部结点 = 相乘），而这棵二叉树又一一对应凸多边形的一个三角剖分：三角剖分中的弦组成二叉树的内部结点，除 v₀v_n 之外的边组成叶子结点。三角剖分 = 矩阵连乘的几何化身。

状态转移方程

(a) 推导过程——考察根三角形

设凸多边形 ⟨v₀, v₁, ⋯, v_n⟩ 的最优三角剖分 T 含三角形 v₀v_k v_n（称为根三角形，k ∈ {1, ⋯, n−1}），则该三角形把原多边形分成三部分：三角形 v₀v_k v_n 自身、子多边形 ⟨v₀, ⋯, v_k⟩、子多边形 ⟨v_k, ⋯, v_n⟩——对应二叉树的根与左右子树。

最优子结构（反证）：若子多边形 ⟨v₀⋯v_k⟩ 存在权更小的剖分，替换进 T 会得到权更小的原多边形剖分，矛盾。故 T 限制在两个子多边形上的剖分也必是最优的。

于是与矩阵连乘同构：枚举根三角形的顶点 k，代价 = 两个子多边形的最优剖分 + 根三角形的权 w(v₀, v_k, v_n)。

(b) 状态转移方程

用 t[i][j]（1 ≤ i ≤ j ≤ n）表示子多边形 {v_{i−1}, v_i, ⋯, v_j} 的最优三角剖分权值：

$$
t[i][j] = \begin{cases}
0, & i = j \\
\min\limits_{i \le k < j} \big\lbrace\ t[i][k] + t[k+1][j] + w(v_{i-1},\ v_k,\ v_j) \big\rbrace, & i < j
\end{cases}
$$

最优值 = t[1][n]（多边形共 n + 1 个顶点 v₀…v_n）；s[i][j] 记录最优剖分位置。与矩阵连乘完全同构——把 w(v_{i−1}, v_k, v_j) 换成 p_{i−1}p_k p_j 就是 m[i][j] 的方程。复杂度 O(n³)。

3.7 图像压缩

问题描述

数字化图像是 n×n 的像素阵列，每个像素有一个 0~255 的灰度值，定长存储一个像素需 8 位。为减少存储空间采用变长模式：不同像素用不同位数存储。方案分三步：

  1. 图像线性化：把 n×n 图像按行展开成一维序列 {p₁, p₂, …, pₙ}；
  2. 分段：将像素分成连续的 m 段 s₁, s₂, …, sₘ，使每段中所有像素的存储位数相同（取该段最大灰度值所需的位数），每段最多 256 个像素；
  3. 存储三方面信息：
    • 第 i 段的段长 l[i]：用 8 位二进制表示；
    • 第 i 段中像素的存储位数 b[i]：用 3 位二进制表示（灰度 0~255 最多 8 位，3 位够编码）；
    • 段内所有像素按 b[i] 位的变长二进制串。

即每段有一个 11 位的段头（8 + 3 = 11）。目标：找一个最优分段，使总存储位数最少。

引例：为什么变长能省空间

例：像素序列 {6, 5, 7, 5, 245, 180, 28, 28, 19, 22, 25, 20}（共 12 个像素）。

  • 定长：每个像素 8 位 → 12 × 8 = 96 bit；
  • 分段存储：{6, 5, 7, 5} | {245, 180} | {28, 28, 19, 22, 25, 20}
    • 第 1 段：l₁ = 4，最大灰度 7 → b₁ = 3 位；
    • 第 2 段：l₂ = 2，最大灰度 245 → b₂ = 8 位；
    • 第 3 段：l₃ = 6，最大灰度 28 → b₃ = 5 位；
    • 像素位：4×3 + 2×8 + 6×5 = 58 bit；
    • 加上 3 个段头：58 + 11×3 = 91 bit。

91 < 96，少了 5 bit。

例 1（16 个像素）：P = {10, 9, 12, 40, 50, 35, 15, 12, 8, 10, 9, 15, 11, 130, 160, 240}
分 4 段：{10,9,12}(b=4) | {40,50,35}(b=6) | {15,12,8,10,9,15,11}(b=4) | {130,160,240}(b=8)
总位数 = 3×4 + 3×6 + 7×4 + 3×8 + 11×4 = 126 bit，而定长 16×8 = 128 bit。

注意：段头是变长模式的代价——分段越多，11×段数的开销越大，所以并不是"段越小越好"，需要统筹优化。

最优子结构

设 l[i], b[i]（1 ≤ i ≤ m）是像素序列 {p₁, p₂, …, pₙ} 的一个最优分段，则：

  • l[1], b[1] 是前 l[1] 个像素 {p₁, …, p_{l[1]}} 的最优分段；
  • l[i], b[i]（2 ≤ i ≤ m）是剩余像素 {p_{l[1]+1}, …, pₙ} 的最优分段。

状态转移方程

(a) 推导过程——考察"最后一个像素"的分段情况

设 s[i] 表示前 i 个像素的最少存储位数，a[i] 表示第 i 个像素 pᵢ 单独存储所需的位数（即 pᵢ 的二进制位数）。站在最后一个像素 pᵢ 的角度，枚举"最后一段"包含多少个像素：

  1. 假设 pᵢ 自成一段（最后一段 1 个像素）：s[i] = s[i−1] + 保存 pᵢ 的代价 = s[i−1] + 1×a[i] + 11；
  2. 假设最后 2 个像素为一段：s[i] = s[i−2] + 2×max{a[i−1], a[i]} + 11；
  3. ……假设最后 i 个像素为一段：s[i] = s[0] + i×max{a[1…i]} + 11；
  4. 到底最后多少个元素为一段？——取使 s[i] 最小的那个 k；
  5. 段内位数取段中最大值：代价 = k × max{后 k 个灰度值的二进制位数} + 11；
  6. 剩下的子问题 s[i−k] 与原问题同构，递归求解即可。

从小下标验证一遍（帮助理解方程）：

  • i = 1（p₁ 只能自成一组）：s[1] = s[0] + 1×a[1] + 11；
  • i = 2：s[2] = min{ s[0] + 2×max{a[1], a[2]} + 11, s[1] + 1×a[2] + 11 }；
  • i = 3：s[3] = min{ s[0] + 3×max{a[1], a[2], a[3]} + 11, s[1] + 2×max{a[2], a[3]} + 11, s[2] + 1×a[3] + 11 }。

规律浮现：min 里的每一项都是"s[i−k] + 最后 k 个像素成一段的代价"，抽象即得状态转移方程。

(b) 状态转移方程

$$
s[i] = \min_{1 \le k \le \min(i,256)} \Big\lbrace s[i-k] + k \times b_{max}(i-k+1,\ i) \Big\rbrace + 11, \qquad s[0] = 0
$$

其中 $b_{max}(i-k+1,\ i) = \max\lbrace a[i-k+1],\ a[i-k+2],\ \ldots,\ a[i]\rbrace$（最后 k 个像素所需的最大位数）。

同时记录取得最小值的 l[i] = k（前 i 个像素的最优分段中，最后一段的像素个数）和 b[i] = b_max（最后一段的存储位数），供构造最优解用。

  • 每个段长不超过 256，故 k ≤ min(i, 256)；
  • 时间复杂度 O(n × min(n, 256)) = O(n²)，空间 O(n)。

3.8 电路布线

问题描述

在一块电路板的上、下两端各有 n 个接线柱。上端第 i 号接线柱通过一根导线连到下端第 π(i) 号接线柱，π 是 {1, 2, …, n} 的一个排列（每根线对应一个 i，记作连线 (i, π(i))）。

相交的定义：对于连线 (i, π(i)) 和 (j, π(j))，若 i < j 而 π(i) > π(j)，则这两条线相交（导线画在板同一侧时必然交叉）。

n 条连线要分布到若干绝缘层上，同一绝缘层上的连线不能相交。电路布线问题：确定哪些连线安排在第一层上，使该层上有尽可能多的连线且互不相交——即求最大不相交连接子集（MNS, Maximum Non-Crossing Subset）。

引例

例：n = 10，π = (4, 6, 1, 9, 3, 8, 5, 7, 10, 2)，即连线集合

$$
\lbrace(1,4),\ (2,6),\ (3,1),\ (4,9),\ (5,3),\ (6,8),\ (7,5),\ (8,7),\ (9,10),\ (10,2)\rbrace
$$

可从中选出 5 条互不相交的线，例如 {(3,1), (5,3), (7,5), (8,7), (9,10)}——下端编号 1 < 3 < 5 < 7 < 10 随上端编号递增而递增，故两两不交。第一层最多布 5 条线。

观察（贯穿全题的关键）：一组连线互不相交 ⇔ 把它们按上端 i 从小到大排序后，下端 π(i) 也严格递增 ⇔ 这组连线对应 π 序列的一个递增子序列。这暗示了后面的解法二。

子问题定义

把问题化为多步决策，自底向上：先求只有 1 条连线时的最大不相交子集，再求 2 条的、3 条的……**如何定义子问题？**引入两个自由度：

$$
N(i, j) = \lbrace (t, \pi(t)) \mid t \le i,\ \pi(t) \le j \rbrace \subseteq Nets
$$

即只考虑前 i 条连线、且下端接线柱编号不超过 j 的连线集合；MNS(i, j) 是 N(i, j) 的最大不相交子集，其大小记为

$$
Size(i, j) = |MNS(i, j)|,\qquad 原问题的解 = Size(n, n).
$$

(i, j) 分别刻画"上端只许用前 i 条"和"下端不许超过 j"——这正是填一张 n×n 表的由来。

状态转移方程

(a) 推导过程——对"第 i 条线"分三种情形

固定 j 轴不变，考察第 i 条连线 (i, π(i)) 是否可用、是否选用：

情形 1：i = 1（只有第一条线）

$$
Size(1, j) = \begin{cases} 0, & j < \pi(1) \\ 1, & j \ge \pi(1) \end{cases}
$$

j 还没大到容得下 π(1) 时，(1, π(1)) ∉ N(1, j)，集合为空；否则可以选它。例：π(1) = 8 时，Size[1][1…7] = 0，Size[1][8…10] = 1。

情形 2：i > 1 且 j < π(i)

(i, π(i)) ∉ N(i, j)——第 i 条线的下端超出了 j，根本不可用，把 i 删掉对结果没有影响：

$$
N(i, j) = N(i-1, j), \qquad Size(i, j) = Size(i-1, j)
$$

情形 3：i > 1 且 j ≥ π(i)——第 i 条线"可用"，但"可用"不等于"该选"，分两种子情形比较：

  • 若 (i, π(i)) ∈ MNS(i, j)（选它）：集合中其余任何线 (t, π(t)) 都应满足 t < i 且 π(t) < π(i)（否则与 (i, π(i)) 相交）。于是剩下的选择范围收缩为"前 i−1 条线、下端 < π(i)"，故

    $$MNS(i, j) = MNS(i-1,\ \pi(i)-1) \cup \lbrace(i, \pi(i))\rbrace, \qquad Size(i, j) = Size(i-1,\ \pi(i)-1) + 1;$$

    注意收缩到 π(i)−1 而不是 j−1：选了 (i, π(i)) 之后，其余线的下端被卡在 π(i) 之前，与 j 无关；

  • 若 (i, π(i)) ∉ MNS(i, j)（不选它）：与情形 2 同理，删掉 i 不影响：

    $$MNS(i, j) = MNS(i-1, j), \qquad Size(i, j) = Size(i-1, j).$$

两种子情形取更优者。用引例中的 (5, 3) 可以说明"不选"可能更优：当 j 较大时，前 4 条线里已有 3 条互不相交（{(1,4),(2,6),(4,9)}），把 (5,3) 选进来反而只能搭配 2 条——所以必须取 max，不能贪心地见线就选。

(b) 状态转移方程

$$
Size(i, j) = \begin{cases}
Size(i-1, j), & i > 1,\ j < \pi(i) \quad \text{（第 } i \text{ 条线放不下，直接继承）} \\[6pt]
\max\lbrace Size(i-1,\ j),\ Size(i-1,\ \pi(i)-1) + 1 \rbrace, & i > 1,\ j \ge \pi(i) \quad \text{（不选 / 选 第 } i \text{ 条线）}
\end{cases}
$$

边界（i = 1 一行单独初始化）：

$$
Size(1, j) = \begin{cases} 0, & j < \pi(1) \\ 1, & j \ge \pi(1) \end{cases}
$$

最优值 = Size(n, n)。时间复杂度 O(n²)（每个格子 O(1)），空间 O(n²)。

解法二：转化为最长递增子序列（LIS）

由引例的观察：一组连线互不相交 ⇔ 它们的上端编号与下端编号同时严格递增。把每条连线 (i, π(i)) 看成数对，按 i 排序后就是序列

$$
\pi(1),\ \pi(2),\ \ldots,\ \pi(n),
$$

最大不相交连线子集 = π 序列的最长严格递增子序列（LIS）。

O(n²) 的 LIS-DP（与 Size 表殊途同归，但状态更省）：设 f[i] 为以 π(i) 结尾的 LIS 长度，

$$
f[i] = \max_{t < i,\ \pi(t) < \pi(i)} \lbrace f[t]\rbrace + 1, \qquad 答案 = \max_i f[i]
$$

构造方案时给每个 i 记前驱 pre[i]，从最长者回溯即得 MNS。

3.3 LCS c[i][j]：前缀 LCS 长度 末字符相等？左上+1 : max{上, 左} 分段函数 + b 表回溯 O(mn) 滚动数组、备忘录；拓展：通配符匹配
3.4 最大子段和 dp(i)：以 i 结尾的最大和 接上前段还是起点重置 dp(i) = max{dp(i−1)+a[i], a[i]} O(n) 分治 O(n log n)、前缀和
3.5 三角剖分 t[i][j]：子多边形最优剖分 根三角形选 v_k（枚举 k 取 min） 与矩阵连乘同构，代价换 w(v_{i−1}v_k v_j) O(n³) （化为矩阵连乘框架）
3.7 图像压缩 s[i]：前 i 像素最少位数 最后一段多长（枚举 k 取 min） s[i−k]+k·b_max+11 O(n²) 记忆化搜索、DAG 最短路
3.8 电路布线 Size(i,j)：前 i 线、下端 ≤ j 的 MNS 第 i 条线选不选（取 max） 选则收缩到 π(i)−1 O(n²) LIS（O(n²)/O(n log n)）

共同心法：站在"最后一个元素"做决策——问"最后一段有多长"（木条、矩阵连乘、图像压缩）还是"最后一个元素选不选"（LCS、电路布线、最大子段和）；决策枚举完取 min/max，记录标记数组，自底向上填表，再回溯构造解。一维状态沿长度递增填；二维状态或按行（LCS、电路布线）或按对角线/链长（矩阵连乘、三角剖分）。

画表要求

  1. 矩阵连乘 / 三角剖分：画 m[i][j]（或 t[i][j]）上三角表 + s[i][j] 断点表，按链长（对角线）从短到长填，最后给出由 s 表递归加括号的最优解；
  2. LCS：画 c[i][j] 表并在每格标注来源方向 b（↖/↑/←），第 0 行第 0 列为 0；从 c[m][n] 按箭头回溯，↖ 尾部字符即 LCS 元素；
  3. 最大子段和：列 a[i] / dp(i) / 是否重置 三行小表，dp 最大处即最优子段终点；
  4. 图像压缩：画候选值三角表（行 = 最后一段长度 k，列 = 像素个数 i，格 = s[i−k] + k·b_max + 11），逐列取最小，另列 s / l / b 三行汇总表；
  5. 电路布线：画 Size[i][j] 二维表（行 = 线号 i，列 = 下端上限 j），逐行填：j < π(i) 照抄上一行、j ≥ π(i) 取 max；回溯路径在表上标出；
  6. 答题顺序：(a) 先写"考察最后一个元素"的推导 → (b) 再写状态转移方程（分段函数 / min-max 式）→ © 最后填表并给出最优解。

易错点

  • 矩阵连乘：合并代价是 p_{i−1}·p_k·p_j（左链行数 × 断点处维数 × 右链列数），三个下标别写错；填表顺序是按链长不是按行；m[i][i] = 0 是边界。
  • LCS：c[i][j] 的 i 对应 X 的前缀、j 对应 Y 的前缀，别串轴；x_i = y_j 时必须取 c[i−1][j−1]+1（可证明不会更差）；LCS 不唯一，b 表在 c[i−1][j] = c[i][j−1] 时取 ↑ 或 ← 都对，只是回溯出的子序列可能不同。
  • 最大子段和：dp(i) 的定义是"以 i 结尾"的最大和，不是"前 i 项"的最大和（后者无最优子结构）；全局答案是 max dp(i) 不是 dp(n)；全负序列答案为 0。
  • 三角剖分：t[i][j] 对应子多边形 {v_{i−1}, ⋯, v_j}（含 j−i+2 个顶点），答案是 t[1][n]（顶点 v₀…v_n 共 n+1 个）；t[i][i+1] = 单个三角形的权，是递推起点。
  • 木条游戏：段长受价格表长度限制；"整根不切"未必最优（如长 6 整根 15 < 3+3 = 16）。
  • 图像压缩：段头是 11 位（8 位段长 + 3 位位数），别漏加；段内位数取段中最大灰度的位数；每段最多 256 个像素（k 的上限）；s[i] 加 11 放在 min 外面和里面等价（每个候选恰含一个新段头），代码里放在外面。
  • 电路布线：j ≥ π(i) 选线时收缩到 Size(i−1, π(i)−1) + 1，不是 Size(i−1, j−1) + 1——选了 (i, π(i)) 后其余线被 π(i) 卡住，与 j 无关；回溯到 i = 1 要特判；MNS 是"选出的线两两不交"的最大集合，不是把所有线都检验一遍。
  • 图像压缩例 {7,6,5,8,129,138,1} 的最优解 62 位大于定长 56 位：DP 求的是"该变长编码方案下"的最优，不代表一定比定长好——段头开销在小规模下可能吞掉收益，答题时按方程算即可。
