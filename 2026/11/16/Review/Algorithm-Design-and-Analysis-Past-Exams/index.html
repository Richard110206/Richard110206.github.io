三条固定套路

  1. 复杂度题：给一段递归代码 → 写递推方程 → 迭代展开求上界 → 写出 O(…) 结论。高频三式：T(n)=2T(n−1)+1 = O(2ⁿ)（汉诺塔）；T(n)=T(n/2)+1 = O(log n)（二分）；T(n)=2T(n/2)+cn = O(n log n)（归并 / 快排）。
  2. DP / 贪心大题固定四件套：策略一句话 → 伪代码 → 给定数据的实例计算（填表 / 求最优序列） → 复杂度分析。
  3. 回溯大题固定四问：画空间树 → 写优化策略（约束函数 + 限界函数各一句）→ 画优化后的空间树（剪枝处标注原因）→ 给最优解（解向量 + 最优值）。

2024 秋

T1 递归方程求解

题目：解递归方程

$$
T(n) = \begin{cases}
7, & n = 1 \\
2T(n/2) + 5n^2, & n > 1
\end{cases}
$$

求 T(n) 的时间复杂度上界。

方法：迭代展开（递归树法）。每层递归：子问题数 ×2，规模 ÷2，新增代价 5n²。

解：迭代展开 k 次（k = log₂n 时规模降到 1）：

$$
T(n) = 2^k T(n/2^k) + \sum_{i=0}^{k-1} 2^i \cdot 5\left(\frac{n}{2^i}\right)^2
= nT(1) + 5n^2 \sum_{i=0}^{k-1}\left(\frac{1}{2}\right)^i
< 7n + 10n^2
$$

几何级数和 Σ(1/2)ⁱ < 2，故 T(n) = O(n²)。

主定理验证：a=2, b=2，n^(log₂2) = n，f(n) = 5n² = Ω(n^(1+ε)) 且满足正则条件 2f(n/2) = 2.5n² ≤ cf(n)，故 T(n) = Θ(n²)。

T4 排队接水（贪心）

题目：n 个人排队接水，第 i 个人的接水（服务）时间为 t[i]，求一种排队顺序使平均等待时间最短（本人接水时间不计入自己的等待时间）。（1）给出策略并证明；（2）写伪代码。

（1）策略（贪心）：服务时间短的人优先。设排序后第 j 位的服务时间为 t(j)，他的等待时间是前 j−1 人服务时间之和，总等待时间

$$
W = \sum_{j=1}^{n} (n-j)\ t(j)
$$

t(j) 越小乘的系数 (n−j) 越大，故升序排列使 W 最小。交换论证：若相邻两人 tᵢ > tᵢ₊₁，交换后总等待减少 tᵢ − tᵢ₊₁ > 0，故任何逆序都可改进，升序即最优。

T5 图像压缩（算法描述）

题目：灰度图像的一行像素 p[1…n]，0 ≤ p[i] ≤ 255。将序列分段压缩：每段长度 ≤ 256，段内所有像素用相同位数 b（b = 段内最大像素值的二进制位数）存储，每段头部开销 11 位（8 位段长 + 3 位位数 b）。给出使总存储位数最少的压缩算法描述。

算法描述（动态规划）：设 s[i] = p[1…i] 的最小存储位数，状态转移——枚举最后一段 p[k…i]（长度 ≤ 256，段内位数 b(k,i) = 段内最大像素位数）：

$$
s[i] = \min_{1 \le k \le i,\ \ i-k+1 \le 256} \lbrace\ s[k-1] + (i-k+1)\ b(k,i) + 11\ \rbrace
$$

按 i 从小到大递推，s[n] 即最优值；用 l[i]、b[i] 记录分段方式回溯出分段方案。完整的状态转移过程与伪代码见下文 2025 秋 T3（像素分割，含 9 像素算例）。

T6 回溯法背包

题目：用回溯法解 0-1 背包：载货量（容量）c = 7，四件货物重量 w = {3, 5, 2, 1}，价值 p = {9, 10, 7, 4}，要求总价值最高。
（1）画解空间树；（2）给出优化策略；（3）画优化后的空间树；（4）给出最优解。

四问作答要点（完整树图与伪代码见下文 2025 春 T5，两题数据相同、解法一致）：

  1. 解空间树：子集树。每件货物 装（xᵢ=1）/ 不装（xᵢ=0），共 2⁴ = 16 个叶结点、31 个结点；结点标注当前重量 cw、当前价值 cp。
  2. 优化策略：约束函数 cw + wᵢ ≤ c 才进左子树（装不下不装）；限界函数 ub = cp + r ≤ bestp 时剪右子树（r = 尚未决策物品的价值总和，全装也超不过当前最优）。
  3. 优化后的树：只生成 10 个结点；✗c 剪去 x₂=1（3+5=8>7）、x₄=1（7+1=8>7）等不可行分支；✗b 剪去 ub = 13、14、11 ≤ 20 的三棵右子树。
  4. 最优解 x = (1, 0, 1, 1)：装货物 1、3、4，重量 3+2+1 = 6 ≤ 7，最优价值 = 9+7+4 = 20。

2025 春

T1 汉诺塔的复杂度分析

题目：给出汉诺塔的递归代码，求其递推方程与时间复杂度。

递推方程：一次调用 = 移 n−1 个盘（两次递归）+ 移最大盘 1 次：

$$
T(n) = 2T(n-1) + 1, \qquad T(1) = 1
$$

解：迭代展开 k 次：

$$
T(n) = 2^k T(n-k) + 2^{k-1} + \cdots + 2 + 1
$$

取 k = n−1：

$$
T(n) = 2^{n-1}T(1) + (2^{n-1} - 1) = 2^{n-1} + 2^{n-1} - 1 = \boxed{2^n - 1}
$$

故时间复杂度 O(2ⁿ)。

T3 矩阵连乘

题目：求矩阵连乘积 A₁A₂A₃A₄ 的最优计算次序，各矩阵维数 p = [10, 20, 5, 25, 80]，即 A₁: 10×20，A₂: 20×5，A₃: 5×25，A₄: 25×80。
（1）写出详细计算过程；（2）给出最优计算次序；（3）给出最优相乘次数。

方法（动态规划）：记 m[i][j] = AᵢAᵢ₊₁⋯Aⱼ 的最少数乘次数，转移——枚举断开点 k：

$$
m[i][j] = \min_{i \le k < j} \lbrace\ m[i][k] + m[k+1][j] + p_{i-1} p_k p_j\ \rbrace, \qquad m[i][i] = 0
$$

按链长从 2 到 n 填表；同时记录断点 s[i][j] = k 用于构造最优次序。复杂度 O(n³)。

（1）详细计算过程：

链长 2：m[i][i+1] = pᵢ₋₁·pᵢ·pᵢ₊₁

  • m[1][2] = 10×20×5 = 1000
  • m[2][3] = 20×5×25 = 2500
  • m[3][4] = 5×25×80 = 10000

链长 3：

  • m[1][3]：k=1：0 + m[2][3] + 10×20×25 = 2500 + 5000 = 7500；k=2：m[1][2] + 0 + 10×5×25 = 1000 + 1250 = 2250 → m[1][3] = 2250，s[1][3] = 2
  • m[2][4]：k=2：0 + m[3][4] + 20×5×80 = 10000 + 8000 = 18000；k=3：m[2][3] + 0 + 20×25×80 = 2500 + 40000 = 42500 → m[2][4] = 18000，s[2][4] = 2

链长 4（m[1][4]）：

  • k=1：m[1][1] + m[2][4] + 10×20×80 = 0 + 18000 + 16000 = 34000
  • k=2：m[1][2] + m[3][4] + 10×5×80 = 1000 + 10000 + 4000 = 15000 ★
  • k=3：m[1][3] + m[4][4] + 10×25×80 = 2250 + 0 + 20000 = 22250

m[i][j] 表：

m[i][j] j=1 j=2 j=3 j=4
i=1 0 1000 2250 15000
i=2 0 2500 18000
i=3 0 10000
i=4 0

s[i][j] 表：

s[i][j] j=2 j=3 j=4
i=1 1 2 2
i=2 2 2
i=3 3

（2）最优次序：s[1][4] = 2 → (A₁A₂)(A₃A₄)。

（3）最优相乘次数 = 15000。验证：(A₁A₂) 花 1000 次得 10×5；(A₃A₄) 花 10000 次得 5×80；(10×5)·(5×80) 花 4000 次；1000 + 10000 + 4000 = 15000。

T4 排队办理业务（最短平均等待时间）

题目：7 位客户排队办理业务，服务时间分别为 {10, 5, 8, 20, 3, 15, 12}（分钟）。

（2）实例计算：升序排列 3, 5, 8, 10, 12, 15, 20，逐位累加等待：

名次 j 1 2 3 4 5 6 7
服务时间 t(j) 3 5 8 10 12 15 20
等待时间（前面人之和） 0 3 8 16 26 38 53

总等待 = 0+3+8+16+26+38+53 = 144（用公式验证：6×3 + 5×5 + 4×8 + 3×10 + 2×12 + 1×15 + 0×20 = 18+25+32+30+24+15 = 144）。

T1 汉诺塔（递推公式与上界）

题目：标准汉诺塔，给出递归代码。（1）写递推公式（5 分）；（2）详细计算求出上界（5 分）。

解：与 2025 春 T1 相同。

（1）递推公式：T(n) = 2T(n−1) + 1，T(1) = 1（移 n−1 个盘两次 + 移最大盘一次）。

（2）详细计算：迭代展开 k 次，T(n) = 2ᵏT(n−k) + (2ᵏ⁻¹ + ⋯ + 2 + 1)；取 k = n−1：

$$
T(n) = 2^{n-1} + (2^{n-1} - 1) = \boxed{2^n - 1}
$$

上界 O(2ⁿ)。

T2 线性时间选择输出前 k 大

题目：输出一个数列里最大的前 k 个数（不要求有序）。
（1）写伪代码（10 分）；（2）分析平均时间复杂度（5 分）。

方法（线性时间选择）：用随机划分 RandomizedSelect 找出第 k 大元素（即第 n−k+1 小），划分保证它右边的元素都不小于它；再一遍线性扫描输出所有 ≥ 它的数。排序是 O(n log n)，此法平均 O(n)。

算例：a = {2, 7, 1, 8, 5, 3}，k = 3。第 n−k+1 = 4 小元素为 5，输出所有 ≥ 5 的数：8, 7, 5。

（2）平均复杂度：随机基准期望把规模降到 ≤ 3n/4，

$$
E[T(n)] \le cn + \tfrac{3}{4}\left(c\cdot\tfrac{3n}{4} + \cdots\right) \le cn\sum_{i\ge0}\left(\tfrac{3}{4}\right)^i = 4cn
$$

即期望 O(n)；加最终 O(n) 扫描，总平均时间复杂度 O(n)（最坏 O(n²)）。

T4 变体跳台阶（DP）

题目：爬 n 阶楼梯，每次可跳 1、2 或 3 阶；每次跳 j 阶消耗 j 点体力，每次跳到某阶还要额外花费 extra(该阶) 体力。设计算法求到达第 n 阶的最少体力消耗，给出伪代码或步骤，并求最坏情况下的时间复杂度（15 分）。

方法（动态规划）：dp[i] = 到达第 i 阶的最少体力。最后一步从 i−j（j ∈ {1,2,3}）跳 j 阶上来，消耗 j + extra(i)：

$$
dp[i] = \min_{j \in \lbrace 1,2,3 \rbrace} \lbrace\ dp[i-j] + j + extra(i)\ \rbrace, \qquad dp[0] = 0
$$

按 i 从小到大递推。

实例计算（n = 6，extra = [2, 3, 1, 4, 2, 5]）：

i 1 2 3 4 5 6
extra(i) 2 3 1 4 2 5
dp[i] 3 5 4 9 8 12

推导：dp[1] = 0+1+2 = 3；dp[2] = min(3+1+3, 0+2+3) = 5；dp[3] = min(5+1+1, 3+2+1, 0+3+1) = 4；dp[4] = min(4+1+4, 5+2+4, 3+3+4) = 9；dp[5] = min(9+1+2, 4+2+2, 5+3+2) = 8；dp[6] = min(8+1+5, 9+2+5, 4+3+5) = 12。

最坏情况时间复杂度 O(n)：每阶只做 3 次转移、常数开销，空间 O(n)。

T5 食堂打饭排队（贪心）

题目：n 名学生去食堂打饭，第 i 名学生打饭时间为 tᵢ，求安排顺序使等待时间最少（打饭时间不算在等待时间内）。（1）使用哪种策略；（2）给出等待时间最少的学生序列；（3）求出最少等待时间（15 分）。

（1）策略：贪心——打饭时间短的学生排前面（与 2025 春 T4、2024 秋 T4 同题）。总等待 W = Σ(n−j)·t(j)，短任务乘大系数 (n−j) 使 W 最小；交换论证：相邻逆序两人交换必减少等待，故升序最优。

（2）最优序列：将 tᵢ 升序排列。

（3）最少等待时间 = 升序后的 Σ(n−j)·t(j)，平均等待再除以 n。

算例：t = {4, 2, 8, 5, 3}（n = 5）。升序得最优序列 2, 3, 4, 5, 8；逐位等待 0, 2, 5, 9, 14，最少总等待 = 30（验证：4×2 + 3×3 + 2×4 + 1×5 = 8+9+8+5 = 30），平均等待 30/5 = 6。

实例：left=1, right=6 → mid=3，a[3]=12 < 17 → 查右半；left=4, right=6 → mid=5，a[5]=25 > 17 → 查左半；left=4, right=4 → mid=4，a[4]=17 命中。共 3 次比较。

T3 最大连续子段和（DP 表）

题目：求最大连续子段和。要求写出算法策略，按给定条件计算（DP 表），并分析时间复杂度。取 a = {−2, 11, −4, 13, −5, −2}。

策略（动态规划）：b[j] = 以 a[j] 结尾的最大子段和，b[j] = max{ b[j−1] + a[j], a[j] }；答案 = max{b[j]}。伪代码见 2024 秋 T3。

DP 表：

j 1 2 3 4 5 6
a[j] −2 11 −4 13 −5 −2
b[j] = max{b[j−1]+a[j], a[j]} −2 11 7 20 15 13

推导：b[1] = −2；b[2] = max(−2+11, 11) = 11（前缀为负，重新开段）；b[3] = max(11−4, −4) = 7；b[4] = max(7+13, 13) = 20；b[5] = max(20−5, −5) = 15；b[6] = max(15−2, −2) = 13。

最大子段和 = 20，对应子段 a[2…4] = {11, −4, 13}。时间复杂度 O(n)。

四类大题的答题模板：

  1. 复杂度题：递推方程 → 迭代展开 k 步 → 代入 k = log₂n（或 n−1）→ 结论。必背三个结果：汉诺塔 2ⁿ−1（O(2ⁿ)）、二分 O(log n)、归并/快排 O(n log n)、T(n)=2T(n/2)+cn² → O(n²)。
  2. DP 题：定义状态含义 → 转移方程（"最后一步"决策）→ 边界 → 按链长 / 下标从小到大填表 → 给出表中最优值与解。矩阵连乘按链长填下三角；最大子段和一行 b[]；图像压缩逐位枚举最后一段。
  3. 贪心题：策略一句话（短任务优先 / 区间 r 最大）→ 伪代码 → 按数据算出序列与总和。排队题最后写"总等待 = Σ(n−j)·t(j)"。
  4. 回溯 / 分支限界题：空间树（子集树 2ⁿ 叶 / 排列树 (n−1)! 叶，结点标注变量）→ 优化策略两条（约束函数剪左，限界函数剪右 / 下界优先队列）→ 优化后树（✗ 处写清是约束还是限界）→ 最优解向量与最优值。
