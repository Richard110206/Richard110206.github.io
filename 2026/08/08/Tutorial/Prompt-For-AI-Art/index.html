5 条万能公式（先记这些）

  • A 通用图文：主体场景 ＋ 主风格 ＋ 色彩光线 ＋ 构图方式 ＋ 材质细节 ＋ 情绪氛围
  • B 手绘风：主体 ＋ 媒介 ＋ 纸张 ＋ 笔触 ＋ 形体 ＋ 色彩 ＋ 构图 ＋ 手工痕迹 ＋ 情绪
  • C 生活场景：具体场景 ＋ 风格类型 ＋ 光线/情绪 ＋ 构图方式 ＋ 材质质感
  • D 教学图文：诗词任务 ＋ 版式类型 ＋ 画面意象 ＋ 文字位置 ＋ 教学目的
  • E 稀缺感：主风格 ＋ 空间结构 ＋ 媒介材质 ＋ 版式系统

避雷：9 个越写越翻车的词

高级 / 精致 / 唯美 / 艺术感 / 有质感 / 电影感 / ins 风 / 氛围感 / 高级感

模型见过太多次 → 出图平庸。换具体描述：留白 60%、字号 8pt、瑞士网格、35mm、柯达 5219、莫兰迪色调……

铁律：风格一次只选 1 个主方向，最多再加 1 种辅助材质——堆得越多，结果越乱。
手绘风心法：治愈感不是把图做得更完美，而是精确控制保留多少"不完美"——歪线、纸纹、出界、没涂满，反而更耐看。

3.14 旅行记忆贴纸卡（照片 → 可收藏小卡）✨

来源：carolinaaafy/travel-memory-sticker-card（GitHub 247⭐ 的 Codex skill）

把一张旅行照片变成一张 3:2 横版可收藏记忆小卡：左半是一张安静的大插画，右半排着 6 枚"手撕贴纸"——就像小时候玩的那种贴纸卡，很好看的旅行纪念品。支持旅行、街景、风景、生活、人像、宠物照片。

固定版式系统（每次出图都一致）：

  • 3:2 横版，暖白哑光无涂层纸，四周连续留 4-5% 纸边
  • 左侧 66-68%：一张近方形无边框大插画，直接落在纸上、边缘粗糙不描线；下方留一条浅色纸带
  • 插画下方正中央、用小圆点分隔、只出现一次 3 个英文关键词
  • 右侧 30-32%：恰好 6 枚可撕贴纸，2-3 枚大、其余小，错落摆放
  • 每张贴纸带厚实暖白手撕粗边 + 轻微扁平纸影
  • 禁止：标题、说明、日期、留言区、邮戳、地址等一切多余文字

画风核心（整卡只允许一种"哑光综合媒介"）：

  • 用 5-8 个哑光色族重建场景，第一眼读 3-6 个大钝形 + 大片安静留白，宁可省略不堆细节
  • 不透明水粉 / 剪纸 / Risograph / 丝网印刷式平涂，均匀细纸纹，边缘不规则、粉笔质感
  • 植被压成 1-3 团色调，建筑压成平面，人物压成无脸剪影
  • 低饱和源色调 + 1-2 个亮色点缀；平涂色影，几乎不用黑色
  • 禁止：马克笔笔触、水彩晕染、照片质感、渐变、3D、动漫、矢量平滑

6 枚贴纸的选法（记忆碎片而非目录）：① 主体碎片 ② 成对/成组变体 ③ 环境形态 ④ 结构碎片 ⑤ 功能物件 ⑥ 小氛围/尺度提示

3 个关键词：写具体（如 Crater Smoke / Blue Summit / Quiet Ridge），别写 Travel / Beautiful 这种空词。

识别锚点：保留原图里一个能"指认地点"的物件（靠剪影、位置、标志色）；文字只在确能定位地点时保留 1 处原文，其余全部抹掉。

完整提示词骨架（复制后替换 {}）：

安装：npx skills add carolinaaafy/travel-memory-sticker-card -g -y

成品自检：一眼可识别场景但先读"大形 + 安静"；整卡只有一种哑光媒介；右侧恰好 6 枚贴纸且有大小层级；关键词恰好 3 个只出现一次；暖纸边完整、无多余文字。

3.15 米色留白 · 水墨解构明信片（废照焕生机）✨

来源：生化肥 - 用不一样的方式记录生活

用法：旅行拍了构图乱、过曝、模糊、残缺的"废照"？直接喂给这条提示词——画面被清空重排成一张干净高级的东方建筑风景明信片，废点全部消失。

为什么能救"废照"（逐句拆解）：

废照的毛病 提示词里对应的话
构图乱 / 杂物多 “提取原图全部景物几何极简简化 + 删除全部细碎纹理、杂物”
过曝 / 光影脏 “删除全部光影”，统一成柔和色块
模糊 / 残损 “无锐利硬线条 + 毛笔淡墨晕染”，模糊变成了水墨晕染
没有视觉重点 “独立米色留白区域 + 大面积留白”，只留干净轮廓
显廉价 / 游客照 “底部纤细优雅衬线英文标题 + 米白哑光纸张”，像美术馆研究图录

替换项：把英文标题换成 {地点英文名，如：SUZHOU} 或想写的一句话；其余交给 AI 复刻原图色彩调性。

四、科研绘图（顶会论文配图）✨

来源：AI垂钓者 - ICML 风格设计 Agent 主题的顶会配图

核心心法：把"画图"变成"写规格书"

你不是在请求 AI 创作，而是在给一个极度听话但毫无审美判断力的排版引擎下达工程指令。
越精确，它越不会自由发挥。 提示词写到 3000 字以上是常态——画布尺寸、十六进制色值、字族字重、箭头线宽全部锁死。

负面约束 > 正面描述：AI 的默认审美会把你拉向 SaaS 仪表盘和科技发布会。把"不要什么"逐条列出，比"要什么"更能控制输出。

四层规格书骨架（递进关系，缺任何一层都会失控）：

层级 任务 关键参数
① 画布与空间比例 让缩略图下仍像论文插图而非海报 图占画布宽度 94%、高度 65%，上下留白
② 结构骨架 决定信息组织方式 几个独立虚线容器 + 中央桥接模块
③ 色彩与字体系统 锁死视觉规范 每个色值给十六进制、每类文字指定字族字重
④ 负面约束清单 抵抗 AI 的默认审美 把不想要的逐条列出

风格关键决策（顶会框架图专用）：

  • 字体：Comic Sans MS——严谨中带一点手绘草图感；几何无衬线体反而显得像商业 PPT
  • 图标：Office 剪贴画风格的小贴纸
  • 配色叙事：双色数据流是整张图的叙事骨架（例：橙色 = 全局协调策略；绿色 = 可靠性证据；灰色 = 中性任务流），读者三秒内抓住故事

9.1 五层拆解法（不"越拆越不像"）

垫图 vs 纯提示词

  • 垫图（图生图）：保留参考图 80% 以上构图、只换主体或调风格 → 风格雷同、易过拟合
  • 纯提示词（文生图）：基于参考风格做大幅创作 → 需要把风格写明白，否则漂移
  • 混合（最稳）：先用纯提示词出 4-6 张草稿 → 选最像的 → 用它当垫图迭代
9.2 出图问题修复表
问题修复思路
太"AI"了加一种真实媒介（纸张 / 印刷 / 胶片），加颗粒与不规则笔触
太满强制留白 30-40%，减少元素数量
太花限制为 2-3 色，强制主色占 70%
太精致写"笨拙、潦草、随性、保留瑕疵"
太平面加大气透视（远景去饱和、模糊）或光线方向
主体模糊在提示词最前面写明主体，并指定其在画面中的位置
文字渲染错把文字部分单独写为「手写字 / 印刷字 / 无文字」三种之一
后印象派出图有"空气感"加"深色轮廓线 + 纯色平铺 + 扁平装饰空间"（见 §6.1）
